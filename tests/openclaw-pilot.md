# One-agent OpenClaw pilot

Status: procedure only until actual evidence is recorded.

## Prerequisites
Select one approved agent and inspect its actual OpenClaw version, built-in Skill Creator, skill roots and loading precedence. Use its current official validation/packaging instructions.
Record the exact source commit for this package and the companion production/critique changes.
Use only an approved existing image provider and the assignment's recorded cost ceiling.
If agent access, image generation, inspection or destination is missing, mark that stage blocked; do not claim completion.
Use a fictional disposable brand and non-confidential material. Do not publish or deliver to a client.

## Run
1. Build the clean package from the selected commit; retain per-file hashes.
2. Install only runtime resources at the confirmed path; verify hashes and discovery in a fresh session.
3. Verify model visibility of all three companion skills and actual image inspection with a known supplied image.
4. Give an ordinary request: “Make an educational social graphic for our fictional bicycle workshop to remind occasional adult riders to check tyre pressure. We want people to save it. No price, offer or pressure number is approved. Use our approved existing production route and project destination.”
5. Capture concept development, selected direction and the complete production packet.
6. Produce the actual image, critique its exact version, make bounded corrections if required and inspect the exact export.
7. Confirm durable storage and the requested delivery separately. Record whichever was requested and its actual receipt; do not treat a text response as image delivery.
8. Run a direct-response café concept plus misleading hook, reference, missing-vision and video-routing cases from behavior-cases.md.
9. Check a supplied wrong/stale asset version is not silently accepted for final review.
10. Record outcome, files/hashes, actual source coverage, cost where relevant, unresolved issues and business impact unmeasured.

## Pass and rollout
Pass only when real discovery, image inspection, concept quality, handoffs and final artifact evidence succeed.
Source presence or local model tests are not a pass.
Keep the GitHub issue open for unresolved gates.
Jack approves wider installation; verify each target's installed source and capabilities.
