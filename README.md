# Z Creative Asset Analysis

This repository contains ZedBiz's skill for developing and assessing still-graphic marketing directions. `SKILL.md` is the authoritative executable instruction; Notion contains the human operating SOP.

## When to use

Use for audience-specific hooks, visual concepts, curiosity, message fit, supplied-draft analysis and reference learning. For a create request, pass the selected direction to graphic production. The package does not create images itself.

## Do not use

Do not use for image export or delivery, final execution verdicts, video or motion, carousels, analytics integrations, causal campaign claims or guaranteed engagement. Production and critique retain their separate jobs.

## Validate and package

Risk: **Operational** because approved source inspection and production coordination are involved. No generation, publication, installation or spending authority is added.

Run the current `z-ai-skill-developer` validator with `--repository` against this repository, then run the host's official validator where available. Build the clean runtime using `python3 tools/build_package.py`. The package contains only SKILL.md and the directories in package-resources.txt; tests and tracking are excluded.

The target OpenClaw built-in Skill Creator and live validation remain required before declaring deployment ready. Do not treat local checks as runtime evidence.
