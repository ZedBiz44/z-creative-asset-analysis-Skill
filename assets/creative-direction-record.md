# Creative Direction Record

Keep this as short as the assignment allows. Omit irrelevant fields rather than inventing values.

- Project and asset/version:
- Audience, one communication job and intended response:
- Placement and known output requirements:
- Coverage and examples reviewed (or no examples supplied):
- Known facts versus inferences:
- Recommended direction and reason:
- Hook and exact copy — Proposed / already approved:
- Visual idea — subject, action/contrast, image role and reading order:
- Payoff — image / caption / destination and what must be there:
- Approved offer, proof, claims, source assets and brand references:
- Protected elements and what not to copy:
- Material unknown, if any:
- One testable hypothesis and suitable success signal:
- Measured evidence or performance unmeasured:
- Next role, exact deliverable, existing project destination and authority:

Production adds the actual draft/export version and owns file creation, storage and delivery.
Critique receives the current version and agreed direction, not an earlier draft.
A record is a production instruction, not proof of a completed graphic or permission to publish.
